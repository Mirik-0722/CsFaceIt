# 6b-quyi loyiha: Sessiya vakolati va demoni tez olish — Implementatsiya Rejasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kirgan o'yinchi admin kalitisiz o'z matchining demosini bir qadamda — havola, fayl yoki (FACEIT ruxsati bo'lsa) umuman hech narsa qilmasdan — saytga keltiradi, natija o'zi tahlil qilinib ko'rinadi; o'z highlight'laridan klip buyurtma qiladi va o'z kliplarini boshqaradi.

**Architecture:** Sessiya endi shaxsdan tashqari vakolat ham beradi, shuning uchun avval kirish mustahkamlanadi va saytlararo so'rovlar rad etiladi. Kim nima qila olishi bitta joyda (`auth/Access`) hal bo'ladi: admin kaliti va `ADMIN` roli hammasini, `USER` esa faqat o'zi o'ynagan match va o'z o'yinchisi uchun. Demo kelgach quvur avvalgidek o'zi ishlaydi; sahifalar bosqichni jonli ko'rsatadi.

**Tech Stack:** Spring Boot 3.5 (Security filtri, `JdbcClient`/JPA, `RestClient`, `@Scheduled`), Flyway `V8`; React 19, TanStack Query; WireMock (soxta FACEIT va Steam), Docker Compose.

**Spec:** `docs/superpowers/specs/2026-10-11-csdemo-uz-alternative-design.md` (manbalar, 6-reja qatori); yo'l xaritasining "6-reja" vazifalari 3–5 va "Ochiq xavflar" dagi roster sharti; `2026-10-12-06a-sign-in.md` ning "Review'lardan qolgan mayda qoldiqlar" bo'limi (mustahkamlash vazifasi); `docs/superpowers/specs/2026-10-11-web-ui-design.md` (komponentlar, "Matchlar" taxtasidagi "Demo yuklash" qutisi). ## Review Focus

1. **O'g'irlangan yoki boshqa saytdan yuborilgan cookie.** Boshqa saytdagi forma yoki skript sessiya nomidan yozish so'rovini yubora olmaydi; chiqish sessiyani darhol tugatadi; admin ro'yxatidan olib tashlangan SteamID keyingi so'rovdayoq `USER` bo'ladi.

## Shartnoma (vazifalar orasida o'zgarmaydigan nomlar)

**Sxema (`V8__session_authority.sql`):** `CREATE INDEX idx_user_sessions_user ON user_sessions (user_id)`; `clips.requested_by BIGINT REFERENCES users(id) ON DELETE SET NULL`; `user_actions (id BIGSERIAL PK, user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE, kind VARCHAR(16) NOT NULL, created_at TIMESTAMPTZ NOT NULL DEFAULT now())` va `(user_id, kind, created_at)` indeksi; `users.last_seen_at TIMESTAMPTZ`, `users.faceit_synced_at TIMESTAMPTZ`.

**Vakolat:** `auth/Actor` — `record Actor(Kind kind, SignedInUser user)`, `Kind {KEY, ADMIN, USER}`, `Long userId()` (`KEY` uchun `null`), `boolean unlimited()`. `auth/Access` — qoidalar yashaydigan yagona joy: `Actor current()`, `requireMatchMember(Actor, FaceitMatch)` → 403 `FACEIT_NOT_LINKED` yoki `NOT_IN_MATCH`; `requireOwnPlayer(Actor, String playerId)` → 403 `NOT_YOUR_PLAYER`; `requireClipOwner(Actor, Long requestedBy)` → 403 `NOT_YOUR_CLIP`. `KEY` va `ADMIN` har tekshiruvdan o'tadi. `ADMIN` — SteamID hozir `auth.admin-steam-ids` da turgan sessiya.

**`USER` uchun amallar:**

| Endpoint | Qoida | Yangi javoblar |
|----------|-------|----------------|
| `POST /api/v1/matches/{id}/demo/import` (ixtiyoriy tana `{"url": "…"}`) | roster a'zosi; `DEMO_IMPORT` kvotasi faqat nimadir navbatga qo'yilganda sanaladi | 403; 429 `IMPORT_LIMIT_REACHED`; 400 `DEMO_LINK_INVALID`, `DEMO_LINK_HOST_NOT_ALLOWED`, `DEMO_LINK_MISMATCH` |
| `POST /api/v1/matches/{id}/demo/upload` | roster a'zosi; `DEMO_UPLOAD` kvotasi fayl saqlanishidan oldin; `PARSED` yoki `ANALYZED` demo ustidan — 409 `DEMO_ALREADY_PARSED` (kalit va `ADMIN` ustidan yoza oladi) | 403; 409; 429 `UPLOAD_LIMIT_REACHED` |
| `POST /api/v1/matches/{id}/demo/analyze` | roster a'zosi; faqat demo `PARSED` bo'lganda | 403; 409 |
| `POST /api/v1/highlights/{id}/clips`, `POST /api/v1/matches/{id}/clips` | o'z o'yinchisi; `CLIP_ORDER` kvotasi faqat yangi klip navbatga qo'yilganda | 403; 429 `CLIP_LIMIT_REACHED` |
| `DELETE /api/v1/clips/{id}` | `requested_by` = shu foydalanuvchi (qator qulfi ostida) | 403 |
| `POST /api/v1/clips/{id}/retry` (yangi) | o'zining `FAILED` klipi; klipning kaliti va sifati bilan qayta buyurtma, muvaffaqiyatsiz qator o'chadi; bitta buyurtma sifatida sanaladi; 201 `ClipResponse` | 404 `CLIP_NOT_FOUND`; 409 `CLIP_NOT_FAILED`; 403; 429 |
| `POST /api/v1/matches/sync` (yangi) | bog'langan o'yinchili sessiya; 202 `{enabled, queued}`; import cheklovidan sanalmaydi | 403 `FACEIT_NOT_LINKED` |

**Javob shakllari:** 429 tanasi `{code, message, retryAt}` va `Retry-After` sarlavhasi (`ApiError.retryAt`, `null` bo'lsa yozilmaydi). `ClipResponse.mine: boolean`. `GET /api/v1/auth/me` ga `limits` qo'shiladi: `ADMIN` uchun `null`, aks holda `{demoUploads, demoImports, clipOrders}`, har biri `{limit, remaining, resetsAt}`; `role` — hozirgi (effektiv) rol. Demo sabab kodlari: `WRONG_MATCH` (yangi), mavjudlari o'z o'rnida. Saytlararo rad: 403 `CROSS_SITE_REQUEST`.

**Sozlamalar:** `PUBLIC_ORIGIN` (ikkala Compose faylida `${PUBLIC_ORIGIN:-…}`; ma'lum manzillar ro'yxati shundan va `CORS_ALLOWED_ORIGINS` dan); `limits.window: 24h`, `limits.demo-uploads: 10`, `limits.demo-imports: 20`, `limits.clip-orders: 5`; `demo.link.allowed-origins` (`DEMO_LINK_ALLOWED_ORIGINS`, standart `https://*.faceit-cdn.net, https://*.backblazeb2.com`), `demo.link.private-hosts` (standart bo'sh; faqat soxta stack), `demo.link.max-duration: 10m`; `demo.match-check.min-share: 0.8`; `faceit.sync.enabled: true`, `interval: 5m`, `seen-within: 3d`, `max-age: 7d`, `users-per-run: 5`, `matches-per-user: 3`, `matches-per-run: 10`, `min-user-interval: 10m`.

**Frontend:** `apiPost(path, {apiKey?, body?})`, `apiDelete(path, {apiKey?})`; `ApiError.retryAt`; `useViewer()` (`canManageDemo`, `canOrderFor`, `canManageClip`); `useRetryClip()`; `matchIdFromDemoName(name)` (`lib/demoName.ts`; backend'dagi egizagi `demo/DemoFileName.matchId(String)`): `<FACEIT match id>-1-1.dem…` → match id. Har yozish amali `['auth','me']` so'rovini yangilaydi.
