# 6a-quyi loyiha: Kirish (Steam va FACEIT) — Implementatsiya Rejasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tashrif buyuruvchi saytga Steam hisobi bilan (FACEIT ilovasi sozlangan bo'lsa, FACEIT hisobi bilan ham) kiradi; sayt uning FACEIT o'yinchisini Steam ID bo'yicha o'zi topadi, tepa panelda maketdagidek avatar, "Statistika" va chiqish paydo bo'ladi.

**Architecture:** Backend'da yangi `auth/` paketi. Foydalanuvchi `users` jadvalida, sessiya `user_sessions` jadvalida (cookie'da tasodifiy token, bazada uning SHA-256 xeshi). Steam — OpenID 2.0 (ro'yxatdan o'tish va kalit talab qilmaydi), javob Steam'ning o'zidan `check_authentication` bilan tekshiriladi. FACEIT — OAuth 2.0 (PKCE), faqat `FACEIT_OAUTH_CLIENT_ID` berilganda yoqiladi. Mavjud `X-API-Key` (admin) va `X-Worker-Token` (recorder) o'zgarmaydi. Frontend sessiyani `GET /api/v1/auth/me` orqali biladi.

**Tech Stack:** Spring Boot 3.5 (Spring Security filtri, `JdbcClient`/JPA, `RestClient`), Flyway `V5__users.sql`; React 19, TanStack Query; WireMock (soxta Steam javobi, faqat soxta stack'da).

**Spec:** `docs/superpowers/specs/2026-10-11-csdemo-uz-alternative-design.md` (10-bo'lim, 6-reja qatori); `docs/superpowers/specs/2026-10-11-web-ui-design.md` (tepa panel, bosh sahifa); yo'l xaritasining "6-reja" vazifalari 1–2. Maket: dizayn kanvasidagi `Main`, `Oyinchi`, `Kliplar` ekranlarining tepa paneli.

- `V1`–`V4` migratsiyalari tahrirlanmaydi; yangi jadvallar faqat `V5__users.sql` da.

- Sessiya cookie'si: `HttpOnly`, `SameSite=Lax`, `Path=/`; so'rov HTTPS orqali kelgan bo'lsa `Secure`. Muddati 30 kun, har foydalanishda uzaytirilmaydi (oddiylik uchun).

## Review Focus

1. **Soxta OpenID javobi:** `claimed_id` boshqa domendan, `return_to` biznikidan boshqa, `check_authentication` `is_valid:false` qaytargan yoki Steam javob bermagan — hech birida sessiya yaratilmaydi; foydalanuvchi xato sahifasiga emas, saytga tushunarli xabar bilan qaytadi.
2. **Kirishni boshqa birovga ulash (login CSRF) va ochiq yo'naltirish:** `state` cookie'dagi qiymat bilan solishtiriladi; `returnTo` faqat ichki yo'l.
3. **Sessiya:** chiqishda bazadagi qator o'chadi (o'g'irlangan cookie ishlamay qoladi); muddati o'tgan yoki noma'lum token 401 emas, "kirmagan" holat (`/auth/me` → 401, boshqa ochiq o'qishlar ishlayveradi); cookie mavjud bo'lishi ochiq sahifalarni buzmaydi.
4. **Mavjud yozuvlar himoyasi o'zgarmaydi:** admin amallari hali ham `X-API-Key` talab qiladi; sessiya ularga ruxsat bermaydi (rol bilan ruxsat — keyingi qadam).
5. **FACEIT topilmasa yoki FACEIT ishlamasa:** kirish baribir muvaffaqiyatli, foydalanuvchi bog'lanmagan holatda qoladi va buni interfeys aytadi.

## API shartnomasi (ikkala vazifa uchun)

| So'rov | Javob |
| --- | --- |
| `GET /api/v1/auth/providers` | `200 {"steam": true, "faceit": false}` — qaysi kirish usullari yoqilgan |
| `GET /api/v1/auth/steam/start?returnTo=/yo'l` | `302` Steam'ga; `csf_login` cookie'si (10 daqiqa, `HttpOnly`) `state` va `returnTo` bilan |
| `GET /api/v1/auth/steam/callback?state=…&openid.*` | muvaffaqiyat: sessiya cookie'si `csf_session`, `302` `returnTo` ga; xato: `302` `/?login=failed` |
| `GET /api/v1/auth/faceit/start`, `…/faceit/callback` | xuddi shu shakl; ilova sozlanmagan bo'lsa `404 AUTH_PROVIDER_DISABLED` |
| `GET /api/v1/auth/me` | `200 {"id": 1, "nickname": "…", "avatarUrl": "…"\|null, "role": "USER"\|"ADMIN", "steamId": "…"\|null, "playerId": "…"\|null}`; kirmagan bo'lsa `401 UNAUTHENTICATED` |
| `POST /api/v1/auth/logout` | `204`; sessiya qatori o'chadi, cookie tozalanadi |

`playerId` — saytdagi o'yinchi sahifasi manzilida ishlatiladigan id (`/players/{playerId}`); FACEIT hisobi topilmagan bo'lsa `null`.

### Rejadan chekinishlar va qarorlar

- **Sessiya faqat `ROLE_USER` oladi — `AUTH_ADMIN_STEAM_IDS` dagi Steam ID uchun ham.** Rejaning "Interfaces" qatorida `ROLE_ADMIN` deyilgan edi; bu "sessiyaning o'zi yozish amaliga yetmaydi" qoidasini buzardi, shuning uchun xavfsiz o'qilishi tanlandi. `/auth/me` dagi `role` — ma'lumot, vakolat emas. Rol bilan ruxsat — 6-rejaning qolgan qismida.
- **Oxirgi xavfsizlik qoidasi admin kalitining vakolatini nomi bilan so'raydi** (`hasRole("ADMIN")`, uni faqat `X-API-Key` beradi): sessiya cookie'si bor, kaliti yo'q so'rov har qanday yozish amalida 403 oladi.
- **Soxta Steam** faqat soxta stack'da (`docker-compose.fake.yml`): WireMock kirishni darhol tasdiqlab qaytaradi. `auth.steam.*` ning standart qiymatlari — Steam'ning haqiqiy manzillari; `claimed_id` namunasi har muhitda Steam'ning o'z hostiga bog'langan.
- **Telefonda tepa panel bir qator** (56px: logo, til, "Kirish" yoki avatar), maketdagi telefon ekrani (KlipMobil) kabi; ichki sahifalarda navigatsiya ostidagi alohida qatorda. Rejada bu aytilmagan edi.
- **Kirmagan tashrifchida `/auth/me` 401 qaytaradi va brauzer buni konsolga xato deb yozadi.** Ishga ta'siri yo'q; shartnomani `204` ga o'zgartirish (backend, frontend, hujjatlar) keyinga qoldirildi.
